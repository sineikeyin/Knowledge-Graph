# 智能地质导向知识图谱平台

本项目包含按老师参考图搭建的首页，以及分享对话中“检索结果页＋规则判定面板”的交互演示。所有井资料、任务和规则均为虚构演示数据。

## 启动

快速查看：双击项目根目录的 `首页预览.html`，即可离线查看首页和规则面板，不需启动服务器。

在 VS Code 终端切换到本项目目录，运行：

```powershell
node server.mjs
```

打开终端输出的本地地址，通常为 http://127.0.0.1:5173。端口占用时自动尝试后续端口。也可运行 `npm run dev`，或通过 VS Code“终端 → 运行任务 → 启动地质导向平台”。不需要安装第三方依赖。

使用 Node.js 20 或更新版本。开发入口 `index.html` 使用 JavaScript 模块，请通过本地服务器访问。修改 `src` 后运行 `node build-preview.mjs` 更新可双击的预览文件。

## 文件结构

```text
index.html                 页面入口
首页预览.html              可双击打开的离线预览

src/main.js                布局、页面与交互
src/styles.css             配色、布局及响应式样式
src/data.js                项目、井、资料和规则样例
src/rules.js               独立的确定性规则计算

assets/favicon.svg         页面图标
docs/页面搭建步骤.html      修订后的页面开发指南
server.mjs                 仅监听本机的静态服务器
tests/rules.test.mjs        规则业务边界验证
.vscode/tasks.json         VS Code 启动任务
```

## 已实现的页面行为

- 顶部菜单、右上角用户信息与待办弹窗，当前项目切换。
- 左侧数据树展开／收起、筛选、对象选择，以及下方属性随选择更新。
- 首页总览、资料目录、知识关联、运行记录切换；知识图示节点可点击。
- 资料清单登记与查看，实际文件不保存、不解析。
- 在混合检索页面显示“选择对象 → 检索资料A07 → 适用规则A08 → 逐项判定A09”。
- 六组演示样例：超限、未触发、缺失、层位未对应、基准不一致、规则冲突。
- 规则阈值／启停修改与演示版本管理；运行记录保留输入、来源、规则版本和结果，可回看及导出 JSON。
- 输入改变后失效旧结果，必须重新判定。
- “生成联合分析”入口独立于规则判定；未接入大模型时明确提示，允许导出分析输入包，不伪造模型结果。
- 开发指南可离线查看、编辑正文并下载修改后的 HTML。

其他模块已建立入口与功能清单，尚未实现其业务处理。真实登录授权、接入／OCR、知识构建、图数据库、搜索、LLM、目标软件联调、备份部署需后续接入服务。

## 规则判定说明

演示规则：“已确认对应的同一层位，厚度差绝对值超过 2 m 时标记待复核”。阈值只是分享对话中的演示值，不是行业标准或专家已审定规则。T3 不依赖大模型；T4 才使用规则结果、图谱事实和证据生成联合分析。

运行数据保存在本机浏览器的 localStorage，不与后端同步。最近保留30条记录，重要结果请及时导出。手工厚度与原始演示记录有区别时，运行快照明确标记“手工输入”。

运行规则测试：

```powershell
node --test tests/rules.test.mjs
```
