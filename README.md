# 智能地质导向知识图谱平台

本项目包含按老师参考图搭建的首页、“检索结果页＋规则判定面板”、02登录与用户权限，03数据接入与治理，04本体与Schema管理，05知识抽取与人工校核，以及06图谱管理与关系查询。本机服务提供实际会话认证、服务端授权、文件保存和审计持久化。所有初始井资料、任务和规则均为虚构演示数据；用户上传的原件与演示记录分别标识。

## 启动

当前整合目录：`E:\Knowledge Graph Platform`。在此目录终端运行 `node .\server.mjs`，或运行 `npm start`。

快速查看：双击项目根目录的 `首页预览.html`，进入独立的离线交互演示；不需要服务器，不能用于真实权限隔离。

在 VS Code 终端切换到本项目目录，运行：

```powershell
node server.mjs
```

打开终端输出的本地地址，通常为 http://127.0.0.1:5173。端口占用时自动尝试后续端口。也可运行 `npm run dev`，或通过 VS Code“终端 → 运行任务 → 启动地质导向平台”。不需要安装第三方依赖。

使用 Node.js 20 或更新版本。开发入口 `index.html` 使用 JavaScript 模块，请通过本地服务器访问。修改 `src` 后运行 `node build-preview.mjs` 更新可双击的预览文件。

初始账号：admin（管理员）、engineer（工程师）、expert（校核专家）、reader（只读）、auditor（审计员），初始开发测试密码统一为 `GeoDemo!2026`。disabled为停用账号。登录页快捷按钮可填入测试账号。真实新增用户使用管理员分配的密码；离线演示用户始终使用固定演示密码。

详细功能、权限规则、接口与验收：[02登录与用户权限实现说明](docs/02登录与用户权限_实现说明.md)。

当前连接器提供文件／CSV／JSON／LAS 2.x ASCII接入，接入任务页仅展示文件解析任务。数据资产筛选、重置及翻页保留当前滚动位置。

数据导入、样例、限制与接口：[03数据接入与治理实现说明](docs/03数据接入与治理_实现说明.md)。

首次启动或升级到0.2.1时，本机服务会在两个内置示例项目中自动补齐演示记录：17份带原件的资料、17条解析任务、20条主数据映射、20次质量校验和5条待知识构建交接。通过、警告、阻断及解析失败均有样例；离线预览也会独立初始化相同演示流程。预置资料名称不再添加演示前缀，来源栏保留“系统演示资料（虚构）”说明，主数据页注明“系统演示映射”，可用“记录来源”筛选区分用户资料。初始化只执行一次，重启不会重复追加，也不会覆盖用户数据；演示映射仅作用于演示资料。

已有本机服务重启后即可自动补齐记录。如需离线执行初始化，先停止平台服务，再运行 `npm run demo:init`；运行中的服务会被脚本检测并拒绝并行写入。

## 已实现的页面行为

- 登录、退出、会话恢复与失效、停用提示；用户、组织、角色、项目成员、对象/字段授权和审计页签。
- 项目、井、资料、字段和本人运行记录由服务端过滤；导入、规则维护、判定和导出再次校验权限。
- 顶部菜单、右上角用户信息与待办弹窗，当前项目切换。
- 左侧数据树展开／收起、筛选、对象选择，以及下方属性随选择更新。数据树与属性按3:2分配高度并独立滚动；较矮窗口允许整页滚动，避免遮挡或裁切底部按钮。
- 业务页面不展示开发说明入口；开发文档保留在README及docs目录。
- 首页总览、资料目录、知识关联、运行记录切换；知识图示节点可点击。
- 数据资产筛选、分页、覆盖统计、详情和左侧属性联动。
- CSV/JSON/LAS 2.x ASCII文件最多5 MB原件上传、哈希去重、授权下载、异步解析与失败重试；CSV/JSON支持最多5000条记录。
- 地层、测井、井轨迹字段映射，井/层位/岩性/区块别名，主数据变更后重新标准化。
- 必填、格式、单位、深度基准、区间、重复、时间检查；可配置采样间距及曲线范围/突变规则。
- 修正生成新版本；质量结果固定数据版本；原件、解析、标准化、校验和知识构建交接可追溯。
- 合格版本提交到知识构建的待处理清单，阻断版本由服务端拒绝；警告需要人工确认。
- 本体模板创建、拖拽添加与移动类型、画布连线、属性及约束编辑；术语搜索、同义词冲突校验。
- 资料标准字段到本体属性的映射配置与实际样例预览；历史指令动作的输入及关联核查。
- 本体草稿保存、送审、批准/退回、发布、复制、版本比较与影响确认；构建资料可固定已发布本体版本。
- 在混合检索页面显示“选择对象 → 检索资料A07 → 适用规则A08 → 逐项判定A09”。
- 正式/演示图独立切换；五类知识的列表筛选、可点击关系图、属性和固定来源证据。
- 3～6 最大跳数的路径、同基准空间邻近、可解释相似井、四类图算法任务及检索上下文交接。
- 知识发布生成历史图版本；按时间/井深对比；正式图快照、恢复前自动备份、恢复核查及索引缓存重建。

## 规则判定说明

演示规则：“已确认对应的同一层位，厚度差绝对值超过 2 m 时标记待复核”。阈值只是分享对话中的演示值，不是行业标准或专家已审定规则。T3 不依赖大模型；T4 才使用规则结果、图谱事实和证据生成联合分析。

本机服务将用户、授权、规则、运行、治理元数据、本体版本/审批/构建绑定、抽取任务/校核/标注/评价/知识发布/本机索引/增量事件和审计保存至 `.runtime/platform.json`，原件保存至 `.runtime/ingestion/files/`。两者均不纳入Git或静态HTTP访问。运行记录按当前用户和实时授权返回。会话在服务内存中，服务重启后需重新登录；中断解析任务可人工重试。离线模式数据保存在独立浏览器存储中，与本机服务互不同步；数据接入仅提供虚构样例，不接收真实文件。旧版工作台浏览器数据保留，但不自动归属任何账号。
