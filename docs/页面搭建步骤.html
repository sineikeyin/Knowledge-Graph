依据：《智能地质导向平台_开发精简版.pdf》。

本文只说明：先搭哪个页面、页面如何布局、依次增加什么交互、覆盖哪些功能点、完成后跳转到哪里。页面名称和菜单组织为实施建议，保留大纲全部9个模块、47项功能。

搭建次序：平台首页 → 登录与用户权限 → 数据接入 → 本体管理 → 知识构建与校核 → 图谱管理 → 混合检索 → 规则与推理 → 两类场景结果 → 典型井与整改回归 → 接口联调 → 运行管理。

其中，两类场景放在检索／推理结果页，典型井与整改回归放在推理模块的子页面；它们是已有模块的页面展开。

第一步：按老师参考图开发平台首页

页面采用“顶部品牌与个人信息 → 横向菜单 → 项目上下文 → 左侧数据树及属性 → 右侧工作区”的布局。文档左侧为阅读目录；实际产品的模块菜单放在顶部横排。

1.1 先搭建全站共用外壳

  1. 顶部左侧放平台名称和标识，右侧放运行状态、待办、帮助、头像及角色信息。
  2. 第二行放横向模块菜单，当前模块高亮；左侧区域专用于数据树和属性。
  3. 第三行放项目／区块／井上下文、数量和工作流程入口。
  4. 主体左侧上方放可搜索、可展开的数据树，下方显示当前选中对象的属性。
  5. 主体右侧放当前模块的标题、工具栏、页签、列表／关系图／结果面板。
  6. 底部放当前工作范围、资料版本和状态信息。

1.2 再开发首页工作区

  1. 概览：资料资产、知识实体、待校核项和已保存判定记录；点击进入对应页面。
  2. 知识关联：以当前井连接地层、测井、轨迹、模型和历史指令；点击节点更新左下属性。
  3. 待办：显示候选审核、场景校核和问题回归入口；打开具体对象。
  4. 典型场景：邻井推荐、地层对比均进入检索结果中的分析面板。
  5. 资料与记录：查看资料目录、来源版本和最近运行结果。

1.3 最后连接首页交互

  • 切换项目／井时同步更新树、属性、统计及右侧内容。
  • 搜索、展开和选择数据树对象；选择不改变资料原始版本。
  • 每个菜单与快捷入口有确定落点，暂未实现的业务明确标识。
  • 个人信息可查看；加载、空数据、失败及无权限状态在后续接入时保留。

完成标志：形成与老师参考图一致的工作台结构，顶部切模块、左侧选对象、下方看属性、右侧做业务，各区域能够联动。

第二步：开发登录与用户权限页面（M1，4项）

页面组成：登录页；用户权限菜单下的用户、组织、角色、项目成员、权限配置、审计页签。

顺序／功能点 页面搭建与操作
1．M1-F2 用户登录与身份认证 做账号密码表单、输入校验、登录、退出、登录失效和停用账号提示；登录成功进入首页。
2．M1-F1 多用户与组织管理 做组织树和用户表格，提供新增、编辑、停用；补充角色与项目成员分配。
3．M1-F3 对象级／属性级权限 做项目、井、文档、图谱对象及字段的权限配置；全站按权限显示菜单、按钮和可见数据。
4．M1-F4 审计留痕 做操作记录列表，支持用户、井、时间、操作和请求编号筛选，打开记录查看操作者、对象与变更。

完成标志：用户登录后只能访问授权范围；所有后续页面接入同一身份与权限机制，服务端同时验证权限。

2.1 本机实现进度（2026-11-18）

已更新代码：登录页及用户、组织、角色、项目成员、权限配置、审计六个页签已实现；首页个人信息、菜单、项目井树、资料及规则操作已接入统一授权。

  • 登录：账号校验、密码显隐、登录/退出、30分钟会话、失效与停用提示；新增账号密码由管理员设置。
  • 管理：组织树与用户搜索分页、新增编辑启停、角色权限矩阵、项目成员角色与井范围。
  • 授权：项目、井、文档、图谱对象及字段限制；后端过滤返回结果，导入、判定和导出再次校验。
  • 审计：操作者、对象、变更前后、结果、请求编号；按用户、井、时间、操作筛选。
  • 运行：在当前项目根目录 E:\Knowledge Graph Platform 中执行 node server.mjs。初始测试账号 admin / engineer / expert / reader / auditor，密码 GeoDemo!2026；disabled 用于停用验证。

打开更新后的登录与工作台页面。双击预览为独立离线演示；通过本机服务访问为后端会话和权限验证。本机数据保存在 .runtime/platform.json；生产部署、统一身份认证和多实例数据库后续接入。

第三步：开发数据接入与治理页面（M2，7项）

页面布局：顶部为区块／井／类型／时间筛选与“导入资料”；下方为资产表格；详情页放原件、解析预览、质量问题、来源版本。

顺序／功能点 页面搭建与操作
1．M2-F7 数据资产目录 先做资料列表、分类筛选、详情和覆盖情况，统一显示归属井、类型、版本、质量与处理状态。
2．M2-F1 连接器库 做“选来源 → 填连接／文件信息 → 配置归属及映射 → 预览 → 提交”的导入向导，包含WITSML、LAS、数据库、文件和API入口。
3．M2-F3 文档解析与OCR 做解析任务与预览，分别查看文本、表格、页码和失败原因；允许查看原件和重试失败任务。
4．M2-F4 主数据与实体归一 做原始名称／别名到标准井、层位、岩性、区块的映射表，提供新增、编辑和冲突提示。
5．M2-F5 数据质量规则与校验 做质量规则和问题表格，定位空值、单位、时间、井深连续性及曲线异常；修改后可重新校验。
6．M2-F6 数据血缘与版本 做“原始记录 → 标准数据 → 实体 → 结论”的来源记录与版本列表，可逐级跳转。
7．M2-F2 随钻实时流接入 做WITSML／MQTT／Kafka接入配置、连接状态、最后接收时间、事件时间、井深和近期记录；提供启停和异常详情。

完成标志：资料可提交、查看处理结果与质量问题；合格资料可点击“构建知识”，带入下一页面。

第四步：开发本体与Schema管理页面（M3，6项）

页面布局：左侧类型树，中间建模画布，右侧属性编辑；术语、映射、动作及版本放在页签中。

顺序／功能点 页面搭建与操作
1．M3-F2 行业本体模板库 做模板选择与预览，包含井、井段、地层、测井、井轨迹、地质模型、历史导向指令及相关对象。
2．M3-F1 可视化本体建模 拖拽添加对象类型，连线定义关系，在属性区配置字段和约束；支持保存、重新打开和校验提示。
3．M3-F3 术语表与同义词 做标准术语、别名、类型、语言及适用范围列表，提供检索与编辑。
4．M3-F5 数据源映射配置 左侧展示源字段，右侧选择本体属性；配置抽取规则，查看样例映射及错误。
5．M3-F6 业务动作定义 做动作类型、输入字段和写入校验表单，用历史指令样本核查关联。
6．M3-F4 本体版本与变更审批 做草稿、送审、审批、发布、版本比较；发布前展示对映射、规则和索引的影响。

完成标志：可建立并发布一个本体版本，在知识构建页面选择使用。

第五步：开发知识抽取与人工校核页面（M4，7项）

页面布局：任务列表和任务详情；审核页采用“左候选列表、中原文、右编辑审核”；评价页显示指标与样本明细。

顺序／功能点 页面搭建与操作
1．M4-F1 流水线编排 做新建任务：选择资料、本体版本及抽取配置；配置解析、分句、NER、关系抽取、归一、质检、入库步骤，展示阶段状态及重试。
2．M4-F2 地学领域NER 做候选实体列表，显示类型、名称、位置、置信度；点击井名、层位、岩性等实体可定位原文。
3．M4-F3 关系抽取 做主体—关系—客体列表，展示“属于、钻遇、邻近、依据”等候选关系及原文来源。
4．M4-F5 表格与曲线头段抽取 做表格／LAS头段预览与结构化结果对照，保留井段、层位、参数、单位和来源。
5．M4-F4 人工校验工作台 按置信度和状态分流候选项，提供接受、驳回、修改；保存前后值、理由、审核人和版本，并提供问题登记入口。
6．M4-F6 抽取质量度量 做专家标注样本与版本选择、评价操作；显示准确率、精确率、召回率、F1、错误类型及每组预期／实际明细。
7．M4-F7 增量与事件驱动更新 做新资料／变更触发配置、更新任务、发布记录以及图谱、索引、缓存刷新状态。

完成标志：候选知识可审核并发布；发布成功后能跳至图谱实体或关系，原文及评价明细可回查。

第六步：开发图谱管理与关系查询页面（M5，7项）

页面布局：左侧类型与筛选，中间实体／关系列表及简要关系图，右侧详情和来源；其他计算能力按页签展开。

顺序／功能点 页面搭建与操作
1．M5-F1 混合存储 先做实体、关系、原件引用和索引状态的统一查看，展示对象之间的关联；存储实现由服务提供。
2．M5-F2 多跳查询与路径分析 选择起点、终点、关系和3～6跳范围，展示路径、节点属性及来源；分别支持五类实体的关联查询。
3．M5-F3 空间索引与邻近计算 做空间范围、目标井和坐标基准输入，展示距离、井／轨迹／断层关系与计算结果。
4．M5-F4 语义相似井混合检索 做候选井列表，展示曲线、层位、工程参数的匹配因素与差异，支持进入检索结果继续分析。
5．M5-F5 图算法库 做算法选择、参数、提交任务和结果查看，包含社区发现、中心度、相似度、连通分量。
6．M5-F6 时序与版本化图 做按时间／井深筛选的历史版本列表及差异记录。
7．M5-F7 快照与回滚 做快照创建、列表、恢复确认、进度和恢复核查记录。

五类实体详情各自必须显示：

  • 地层：井／井段、上下层位、构造、标准名称及来源。
  • 测井：曲线／测量记录、所属井段、层位、单位及深度基准。
  • 井轨迹：井眼、轨迹点、井段、地层／模型、坐标及深度基准。
  • 地质模型：区块、地层、井／轨迹、模型版本、来源及适用范围。
  • 历史导向指令：目标井段、时间、依据及对应地层／轨迹对象。

完成标志：从任一对象可查关系、属性与证据，并将查询上下文带入检索页面。

6.1 本机实现进度（2026-11-19，v0.5.0）

已实现 M5-F1～F7：图谱管理提供实体／关系和来源、多跳路径、空间邻近、相似井、图算法、时序与版本、快照与恢复七个页签。正式知识只读取已校核发布事实；虚构五类图谱与坐标单独切换。对象、路径或候选井可带入混合检索上下文。

空间计算要求同一坐标框架并保留来源；相似井按有效因素加权并展示缺失情况。图算法含连通分量、度中心度、Jaccard及标签传播社区发现。知识发布生成历史图版本；恢复前自动备份，恢复后重建索引和缓存并核查关系完整性。

本机版本沿用私有文件与 JSON 知识存储；外部图／向量数据库、生产空间投影服务需后续接入。快照只覆盖正式知识图和派生视图，不覆盖原件、本体与用户权限。使用、接口及验收详见项目 docs 下的《06图谱管理与关系查询_实现说明.md》。

第七步：开发混合检索与规则判定面板（M6，4项）

根据分享对话中的设计，在检索结果页加入“规则判定”面板。A07、A08、A09在同一上下文内顺序展示，T3可独立于大模型运行和验收。

顺序／功能点页面搭建与操作
1．M6-F1 统一混合检索选择目标井、井段、场景和必要的参考井，显示实体、关系路径及资料片段；在面板“检索到的资料”区展示当前／参考层位、分层或测井记录与匹配依据。
2．M6-F3 来源与证据查看点击资料、规则判定或引用，定位原文页码、井段或源记录，保留来源与版本。
3．M6-F2 基于图谱证据的问答以事实和原文生成带引用回答；提供独立“生成联合分析”入口，将事实、规则判定和引用交给大模型用于T4。
4．M6-F4 权限感知检索资料、规则、证据与模型上下文遵循统一权限；受限内容由服务端过滤，前端显示允许访问的范围。

7.1 规则判定面板布局

另行操作：生成联合分析（A10／T4，使用事实、判定和证据）

7.2 依次实现的交互

  1. 选择分析对象，保留当前项目、井和井段；必要时选择参考井。
  2. 检索资料并展示可定位的来源，说明哪些输入可用、哪些缺失。
  3. 按场景和井段条件筛规则，显示适用原因与规则版本。
  4. 点击“运行规则判定”，逐项展示实际值、计算或比较条件及结论。
  5. 保存本次输入、来源、规则版本、判断过程和结果；修改输入后要求重新运行。
  6. 点击“生成联合分析”才进入大模型环节，未接入服务时明确提示，不能把规则结果当成模型分析。

完成标志：一个面板可以复核“资料找对没有、规则选对没有、判断算对没有”，且每次运行可回查。

第八步：开发规则库与判定逻辑（M7的规则及分析部分，3项）

“规则与推理”菜单负责规则维护和历史记录；主要判定入口放在检索结果页的规则判定面板。两个入口共用同一套规则、计算和运行记录。

顺序／功能点页面搭建与操作
1．M7-F1 专家规则管理与关联维护条件、结论、适用范围、来源、版本和启停；在A08区说明为什么选中，分别显示无适用规则和规则冲突。
2．M7-F3 知识推理与依据记录将本次实测值代入已选规则，记录输入、单位、基准、计算与逐项判断，在A09区输出明确结论；支持人工意见和回查。
3．M7-F8 图谱与大模型联合推理单独触发联合分析，将相关图谱事实、规则判定与文档证据交给大模型；输出理由、支持／反对证据、不确定性、引用和模型／提示模板版本。

8.1 首个可演示规则

同层位厚度差复核：两井为已确认对应的同一层位，单位和深度基准一致，厚度差绝对值超过2 m时标记待复核。2 m仅为演示阈值，正式规则及阈值由专家确认。

演示输入／情况面板应显示的结果
目标8 m、参考11 m差值3 m > 2 m：需要提示风险／厚度差待复核，附两条输入及来源。
目标8 m、参考9 m差值1 m，不超过2 m：未触发规则。
任一井厚度缺失或无效资料不足，暂时无法判断；不使用零值替代。
层位尚未确认对应本规则不适用／无适用规则，不显示“未触发”。
单位或深度基准不一致标明不可比及缺少的统一基准，暂不进行差值判断。
同一工况出现相反规则规则冲突，待人工处理；不静默选择结论。

8.2 历史记录页

按运行编号查看井／井段、场景、实测值、资料与规则版本、逐项判断、结论、原文引用和人工意见。规则更新后保留旧记录中的原版本。

完成标志：在同一面板运行超限、未触发、资料不足、不适用和冲突样例；T3可独立留证，T4另行核查模型是否正确使用这些输入。

第九步：在检索／推理结果中补齐两类场景

两个场景从检索结果页发起，共用规则判定面板。先展示事实和规则判定，再由“生成联合分析”触发大模型分析，不新增独立应用模块。

9.1 邻井推荐结果区

  1. 在检索页增加“邻井推荐”入口及参数面板：目标井、层位、井段、空间范围和关注问题。
  2. 做候选井列表：距离、资料覆盖、匹配因素、历史案例和差异。
  3. 做联合分析区：推荐理由、可参考性、适用规则、关系路径、原文及不确定性。
  4. 增加人工接受／驳回／修改意见、保存结果和登记问题。
  5. 无符合条件邻井时显示原因；仅有候选列表时明确分析尚未完成。

9.2 地层对比结果区

  1. 增加目标井、人工指定1～2口参考井、层位／井段选择。
  2. 检查单位、深度基准、层位对应和资料缺项，显示冲突及不可比原因。
  3. 做按已知层位排列的对比表，展示各井深度、曲线摘要、模型与来源。
  4. 做分析说明：相同层位的异同、证据冲突、不确定性及待核查项。
  5. 增加逐项原文定位、人工意见、保存结果和登记问题。

完成标志：两类场景都有参数、结果、规则／事实依据、原文和人工校核入口。

第十步：开发典型井、人工校核与整改回归子页面（M7剩余1项）

在“规则与推理”菜单下增加“典型井与整改回归”，内部使用“案例、结果校核、问题台账、回归记录”页签。

顺序／功能点 页面搭建与操作
1．M7-F6 典型井应用与回归验证 建立案例 → 选择资料与固定运行版本 → 执行两类场景 → 保存专家意见 → 登记问题／责任人 → 记录整改版本 → 复测原失败及受影响用例 → 对比前后结果 → 人工确认关闭。

结果校核复用知识构建页的接受／驳回／修改能力，问题登记也可从图谱、检索和推理结果直接进入。

完成标志：一个问题有发现依据、整改版本、回归结果和人工关闭依据；回归失败保持待处理。

第十一步：开发开放接口与软件联调页面（M12，4项）

页面布局：分为“图谱接口A12”“智能体／目标软件A13”两组；共用文档和请求详情组件，分别保留记录。

顺序／功能点 页面搭建与操作
1．M12-F1 统一查询与推理接口 做接口目录、字段／鉴权／错误码说明、请求响应示例和任务状态查询，覆盖实体关系、检索与推理。
2．M12-F3 地质导向软件适配 做目标软件配置和井／井段、查询条件、结果、接收状态映射，展示目标软件的接收状态。
3．M12-F6 智能体工具调用与联调 做工具目录、调用记录及“智能体 → 图谱／推理 → 目标软件”链路详情。
4．M12-F5 接口鉴权与稳定性 两组分别展示正常、越权、超时／重试、限流、重复请求、断线恢复、连续调用的状态与日志，关联请求和任务。

完成标志：两类接口各自可追溯；开发模拟记录与真实联调记录明确标识。

第十二步：开发部署与运行管理页面（M13，4项）

页面布局：运行概览、任务／接口日志、备份恢复、安全与导出、部署信息。

顺序／功能点 页面搭建与操作
1．M13-F1 运行日志与监控 按导入、抽取、检索、推理、接口筛选；显示状态、耗时、错误、请求编号，分别统计A12和A13。
2．M13-F2 备份与恢复 做备份清单、备份／恢复任务、进度及恢复后一致性核查记录。
3．M13-F3 加密、脱敏与导出保护 做敏感字段与导出策略、受保护字段展示和导出记录；凭据不进入普通日志。
4．M13-F4 私有化部署包 做服务版本、健康状态、配置模板、初始化／升级／回退记录及部署资料查看入口。

完成标志：能够从失败任务定位日志，查看备份与恢复核验，确认实际运行版本及部署状态。

最后：把页面连接起来检查

依次走通：

  1. 首页 → 导入资料 → 查看解析及质量问题。
  2. 数据资料 → 选择本体 → 构建 → 人工审核 → 发布。
  3. 已发布知识 → 五类实体关系 → 检索 → 原文证据。
  4. 检索结果 → 规则关联 → 实测判断 → 联合分析。
  5. 检索结果 → 邻井推荐／地层对比 → 专家校核。
  6. 校核意见 → 问题 → 整改 → 回归 → 人工关闭。
  7. 各页面操作 → 审计／运行日志；接口结果 → 两类联调记录。

每个页面按“布局 → 列表／表单 → 按钮交互 → 详情／证据 → 状态提示 → 保存与跳转”的顺序搭建，并补充加载、空结果、失败、无权限和重试状态。

功能覆盖核对：M1共4项、M2共7项、M3共6项、M4共7项、M5共7项、M6共4项、M7共4项、M12共4项、M13共4项，合计47项。抽取评价对应A01，五类关联对应A02～A06，检索／规则／推理对应A07～A10，两类场景对应A11，接口对应A12～A13，典型井／校核／回归对应A14～A16。

以上步骤覆盖全部功能的页面入口、交互和结果呈现。抽取、存储、检索、推理、权限、安全、部署等实际能力需要接入相应服务后完成，最终沿用大纲的六类测试进行验证。
