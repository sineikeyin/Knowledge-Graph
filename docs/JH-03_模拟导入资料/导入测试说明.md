# JH-03 模拟导入资料与测试说明

本目录包含11份CSV/JSON文件，用于人工检查当前平台的导入、解析、字段映射、主数据归一、质量校验、修正复检及新版本上传。所有记录均为虚构测试数据，不代表实际井资料。文件名不额外添加示例前缀。

## 导入前设置

- 使用有导入、治理权限的账号；如需测试“构建知识”交接，使用管理员或同时有知识构建权限的账号。
- 当前项目：鄂尔多斯示例工区；当前区块：示例区块 A；归属井：JH-03。
- 标准层位：长 8₂。请保留字符“₂”，不要写成JH-01使用的“长 8₁”。
- 文件编码选择UTF-8。CSV为UTF-8带BOM、逗号分隔；JSON为UTF-8，使用records数组。
- 导入向导中，按下表选择资料类型。“地层”不是“测井”，“井轨迹”单独选择。
- 在“数据资产”可将记录来源筛为“用户资料”，只查看本次手动导入的资料。

## 建议操作顺序

只想先试一次正常导入：使用01，确认自动映射，预览并上传，等待解析完成，再点击“运行质量校验”；应通过，可查看原件、标准表格、版本和交接入口。

完整测试建议按04 → 01 → 02 → 03 → 06 → 09 → 05 → 07 → 08 → 10 → 11进行。先完成04的主数据映射，可以减少后续重复标准化操作。02有37条测井记录，可检查解析预览翻页；03有10条轨迹记录。

“解析完成”与“质量通过”是两个状态。上传后需要在资料详情运行正式质量校验；导入向导的预检查不替代正式校验。

## 04：主数据归一

初次导入04时，预检查会提示名称问题，可以确认上传后运行正式质量校验，查看阻断定位。在“主数据映射”选择归属井JH-03，新增以下映射，不要修改系统已有的示例映射：

| 实体类型 | 原始名称／别名 | 标准名称 |
| --- | --- | --- |
| 井 | JH03联调井 | JH-03 |
| 层位 | 长8二联调名 | 长 8₂ |
| 岩性 | 细砂岩联调名 | 细砂岩 |
| 区块 | 鄂尔多斯A联调区 | 示例区块 A |

回到04的资料详情，打开“字段映射”，保留原列对应关系并保存新版本，使主数据重新应用；然后运行质量校验，应通过。岩性映射用于查看归一效果，当前规则不会单独因岩性别名缺失而阻断。

当前实现中，修改某井的用户主数据映射，会使该井已有的用户资料标为“待重新标准化”。如果先导入了01等文件，再添加上述映射，需对这些文件重新保存字段映射并复检；系统示例资料不受用户映射影响。

## 05：质量阻断与修正复检

本文件能正常解析，但会被质量规则阻断。行号指解析结果中的“数据行”，对应原CSV物理行号为数据行号加1。

| 数据行 | 问题 | 修正字段及原始值 |
| ---: | --- | --- |
| 1 | 底深小于顶深，推导厚度为负数 | 底深 → 3096.5 |
| 2 | cm不是当前支持的深度单位 | 深度单位 → m |
| 3 | 深度类型为空 | 深度类型 → MD |
| 4 | 参考基准未确认 | 参考基准 → KB |
| 5 | 文件中的井名与归属井不符 | 井名 → JH-03 |
| 6 | 层位不在已确认名称中 | 层位 → 长 8₂ |
| 7 | 厚度为非法文本abc | 厚度 → 0.5 |

可从质量问题的“修正”入口处理，也可在“解析预览 → 修正指定行”按上表处理。每次修正产生新版本，原件不变；处理全部问题后重新运行校验，应通过。检查旧版本仍可回看原问题及原校验记录。

## 07：质量警告与人工确认

导入07后，在“运行质量校验”对话框设置：最大采样间距1 m、曲线最小值0、最大值120、相邻曲线最大变化值50。

该文件的GR单位为API，阈值仅用于功能测试。应得到4项警告：一次超过最大值、两次相邻值变化超限、一次井深间距超限。未设置这些阈值时，当前基础规则会通过，这是预期行为。

有知识构建权限的账号可点击“构建知识”，检查警告确认勾选项。勾选后只会进入“待知识构建”清单，不代表已经生成知识实体。

## 08：前置解析拦截

08故意缺少一列。在向导点击“下一步”时，应立即提示列数与表头不一致，不能继续预览提交。当前前后端共用解析器，因此这类错误先被前端拦截，不会新增接入任务；不要把“任务列表没有新任务”误判为数据丢失。

## 09：英尺转米

09的顶深、底深、厚度均使用ft。解析后的顶深应依次为3096、3099、3102 m，底深为3099、3102、3105 m，厚度均为3 m。原始英尺值可在原始解析输入或下载原件中回查。此处只做长度单位换算，不做MD与TVD转换。

## 10与11：重复重叠问题和新原件版本

先导入10，检查第2行重复及第2、3行区间重叠问题。当前页面没有删除单行的入口，此场景可用修正版原件解决。

打开10的资料详情，点击“上传新版本”，选择11；不要从全局“导入资料”另建资产。完成预览和上传后，重新运行质量校验，应通过。检查资产ID保持不变、当前版本变为v2、旧版本仍可回看。列表资产名称可能仍沿用10，实际原文件名会在版本详情中显示11。
