# 02 登录与用户权限：实现与验证说明

更新时间：2026-11-18。对应 M1-F1～M1-F4。

## 运行

在项目目录运行 `node server.mjs`，访问终端打印的本机地址。默认端口5173，冲突时依次尝试5174～5183。无需安装第三方依赖。

双击 `首页预览.html` 使用离线交互示例。离线模式与服务端数据独立，不提供安全隔离，不用于真实业务资料。

## 初始测试账号

所有初始账号的开发测试密码为 `GeoDemo!2026`。登录页提供填入账号的快捷按钮，仍需点击登录。

| 账号 | 角色 | 初始数据范围 |
| --- | --- | --- |
| admin | 系统管理员 | 全部示例项目和井，六个管理页签 |
| engineer | 地质工程师 | 项目p1的w1、w2；导入、检索、规则运行和导出 |
| expert | 校核专家 | 项目p1的w1、w2、w3；校核模块及规则运行；校核业务仍沿用原模块开发范围 |
| reader | 只读用户 | 仅p1/w1；隐藏井段、厚度、距离；禁止导入和判定 |
| auditor | 审计员 | 审计页签；没有项目资料范围 |
| disabled | 已停用 | 禁止登录，用于验证停用提示 |

## 已实现页面

- 登录：校验、显示密码、登录中、错误提示、停用提示、30分钟固定有效期、退出、刷新恢复会话。
- 用户：组织筛选、搜索、分页、新增、编辑、重置密码、启停。保护最后一位启用管理员。
- 组织：树、详情、成员列表、新增和编辑、调整上级、启停；防止循环及带有效成员的组织被停用。
- 角色：角色列表、功能权限矩阵、新增和编辑、关联人数。
- 项目成员：按项目分配角色和井范围、调整范围、移除成员并清理授权。
- 权限配置：按用户配置项目、井、文档、图谱对象的允许操作及隐藏字段，支持撤销限制。
- 审计：按用户、井、操作、时间和请求编号筛选，详情含变更前后数据。显示最新200条匹配记录，总量独立显示；日志保存在本机文件中。

## 权限语义

默认无项目数据权限。系统角色管理公共入口，项目成员角色决定项目操作能力，成员井列表决定数据范围。只有系统管理权限可修改组织、用户、角色、成员与授权；项目管理员模板目前用于项目业务操作，不提供委派授权。

对象规则为限制规则，不增加角色操作能力。匹配优先级：具体文档或图谱对象 → 井 → 项目。没有对象规则时继承成员井范围和角色能力；允许操作为空时对象不可访问。关联视图采用保守字段过滤：同井对象/文档的隐藏字段也从井概览和相关摘要隐藏，避免从别处读取受限属性。

后端每次读取当前用户、角色与成员状态。工作台、树、资料、任务、统计和本人判定记录均取授权结果；受限字段直接不返回。导入、规则修改、判定、导出在服务端再次验证。判定需要目标井、参考井和分层证据均可见，厚度、井段及来源字段可用。导出重新校验原运行涉及的对象，不直接下载旧缓存。

前端菜单与按钮消费相同授权结果；切换账号清空工作状态。无项目、无权限、加载失败和重试有独立页面状态。

## 本机后端

- `server/app.mjs`：HTTP接口、scrypt加盐密码哈希、随机会话令牌、HttpOnly/SameSite Cookie、CSRF令牌、同源检查、登录失败限速、请求编号、原子持久化。
- `src/access-model.js`：共享权限模型、管理规则、业务权限和审计。只由后端或离线打包器读取，HTTP不公开该文件及初始数据文件。
- `.runtime/platform.json`：用户、授权、业务记录与密码哈希；不包含明文密码，不通过静态路由公开。该目录已忽略。
- 会话在内存中；服务重启需重新登录，用户与授权数据保留。停用用户或重置密码撤销该用户已有会话。
- 服务只监听127.0.0.1。适合本机开发验收；多实例数据库、统一身份认证、生产HTTPS部署、备份和日志归档需后续工程化接入。
- 离线模式使用固定示例密码，新建示例用户也使用同一示例密码；密码输入禁用，页面明确提示。

## 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | /api/auth/login | 登录 |
| GET | /api/auth/me | 当前身份、CSRF令牌、会话到期时间 |
| POST | /api/auth/logout | 注销 |
| GET | /api/workspace | 授权项目、井、字段、资料、待办、本人运行记录及操作能力 |
| GET | /api/admin | 管理页数据；审计员仅获得审计数据 |
| POST | /api/users | 新增/编辑/启停用户、重置密码 |
| POST | /api/organizations | 新增/编辑组织 |
| POST | /api/roles | 新增/编辑角色 |
| POST | /api/members | 保存或移除项目成员 |
| POST | /api/grants | 保存或撤销对象规则 |
| POST | /api/business/import | 登记资料清单，不保存原文件 |
| POST | /api/business/run | 确定性规则运行并保存 |
| POST | /api/business/rule-edit | 保存规则参数与新版本 |
| POST | /api/business/export | 重新校验后返回本人运行记录 |

新增不带id，编辑带id；成员和对象规则的移除带 `remove:true`。所有POST除登录外需当前会话Cookie和 `X-CSRF-Token`。错误返回message和requestId；401重新登录、403无权限、429登录限速。

## 验证

运行 `npm test`，同进程执行规则测试、权限边界、真实HTTP鉴权、会话撤销与到期、持久化和离线预览验证。修改src后运行 `npm run preview:build` 生成最新离线页。

浏览器验收：管理员登录后检查六个页签及编辑表单；退出后用reader验证只有一口井、字段受限且没有写操作；用auditor验证没有项目资料且只显示审计页签。未来尚未实现的本体、构建、校核、接口等业务仍明确保留占位状态，不因拥有菜单权限而视为业务已完成。
