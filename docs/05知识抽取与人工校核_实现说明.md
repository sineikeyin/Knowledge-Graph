# 05 知识抽取与人工校核（0.4.0）

入口为顶部“知识构建”。本次在现有 03 数据治理、04 本体版本、登录和授权之上实现 M4 的七项功能，包含真实本机服务与可双击离线演示。启动命令仍为 `npm start`；更新已运行服务后，请重启并刷新页面。

## 对应功能

| 功能 | 当前实现 |
| --- | --- |
| M4-F1 流水线编排 | 新建任务选择固定交接资料、已发布本体、分流阈值、是否抽关系与术语归一。依次执行解析、记录切分、实体、关系、归一、质检、候选入库；保存执行状态、次数、摘要和错误，可重试失败步骤 |
| M4-F2 地学实体识别 | 对地层、测井、轨迹的结构化字段生成井、井段、层位、岩性、曲线记录、轨迹点候选。展示类型、名称、置信度与源行 / JSON记录；点击候选高亮原件单元格 |
| M4-F3 关系抽取 | 依据固定本体与同一记录的实际实体生成“隶属于”“钻遇”“具有岩性”等主体—关系—客体。只生成有数据支持、符合本体端点类型的关系 |
| M4-F5 表格与曲线头段 | 原表、治理值与候选对照；支持 LAS 2.x ASCII 的 WELL、曲线、单位、参数头段与样本物理行号，保留来源与深度基准 |
| M4-F4 人工校核 | 左候选、中原文、右编辑。按实体 / 关系、置信度、审核状态分流。接受、驳回、修改并接受；保存前后值、理由、审核人、候选和任务版本、本体版本；问题登记附原件证据 |
| M4-F6 质量度量 | 独立保存专家标注版本；对固定的原始抽取输出评价，展示准确率、精确率、召回率、F1、TP / FP / FN及预期 / 实际明细分页和按权限导出。人工修订不覆盖原始预测 |
| M4-F7 增量更新 | 为资料类型绑定固定本体；合格的新交接版本触发构建，每个触发器 / 交接只建一次任务；更新任务仍需审核。发布记录展示本机知识库、名称索引、统计缓存刷新，并可跳转图谱知识与原文 |

## 使用流程

1. 在数据接入中上传 CSV / JSON，选择井与资料类型，完成映射、归一、质量校验并“构建知识”。原有虚构治理样例也可用于体验。
2. 在本体管理创建模板、送审、批准并发布。任务只接受已发布版本，本体后续修改不会改变旧任务快照。
3. 进入“知识构建 → 新建抽取任务”，选择资料和本体；同一任务不能选择同一资产的多个版本。单任务最多10份资料、2000条输入记录。
4. 在抽取任务查看各阶段记录。完成后进入“人工校核”，逐项确认原文、单位、井段与字段；修改属性时使用“保存修改并接受”。
5. 每次校核都要填写理由。存在 Schema 错误的候选必须先修正或驳回；驳回实体后，其关系也需处理。
6. 所有候选接受或驳回后，有发布权限的账号可确认发布。已接受关系的两个端点必须同时接受。发布后该任务冻结；改动知识应新建任务。
7. “增量与发布”提供发布记录和图谱跳转。在图谱页点击“查看知识与证据”，可查看已发布对象、关系、原件版本和人工校核依据。
8. 在“质量评价”保存独立专家标注版本，选择版本运行评价。预填预测仅是 JSON 编辑格式，必须根据来源独立修订，不能直接当作金标准。

## 原件、归一与版本

- 任务保存资料版本、交接时质量记录、原件摘要、本体全文 / 修订号、抽取器版本与配置；后续原件或本体更新不会漂移旧任务。
- 原件证据来自同一原始文件的首次解析。治理修正的底深等值显示在候选和对照表，原件文本不被改写；两者都有版本编号和变更原因。
- 已确认井别名以归属井标准井号生成知识；原文高亮仍保留旧井名。层位、岩性、区块采用治理映射与本体术语。
- 同一资料的后续发布替代其现行知识；旧事实、发布、候选与审核历史保留。较旧的数据版本不能覆盖已发布的更新版本。
- 图谱列表为真实已审核数据；原有固定“示例图谱”仍单独标识。

## LAS 使用

选择资料类型“测井”，上传 [05_LAS曲线头段_虚构示例.las](samples/05_LAS曲线头段_虚构示例.las)。当前支持 LAS 2.x ASCII、`WRAP=NO`，深度为首列，至少一条曲线。多曲线展开为逐曲线测量记录，展开后最多5000条；文件仍最多5 MB。

头段保留原始行号、助记符、单位、值与说明，NULL转为空值并由质量门槛拦截。示例通过 `DEPTTYPE` 和 `DREF` 明确 MD / KB；实际文件未包含明确基准时，应在导入映射中填写经确认的默认值。系统不会根据文件格式自动猜测 MD 或 KB。

LAS 3.x、二进制和 WRAP=YES 本次不支持，解析时返回具体原因；PDF / DOCX / OCR 未接入。

## 评价口径

每个预期 / 实际对象包含 `kind`、`typeId`、`value`。实体按全部属性严格匹配；关系使用主体与客体的属性内容，而非任务内候选编号。重复项按多重集计数，不因去重抬高分数。关系端点属性不同也计为不匹配。

精确率为 TP/(TP+FP)，召回率为 TP/(TP+FN)，F1为二者调和平均。抽取没有有限的真负例全集，页面“准确率”明确采用集合准确率 TP/(TP+FP+FN)。分母为空时显示0，不宣称100%。指标严格对应当前标注和输入样本，不代表独立测试集上的模型泛化能力。

## 权限、存储与边界

- 沿用 `construction`、`review`、`publish` 权限以及项目、井、对象、资料、字段授权；工程师增加一次性知识构建入口，专家可校核，管理员 / 项目管理员可发布。既有自定义权限在迁移后不会反复恢复。
- 请求在服务端重新鉴权；原件受限时任务快照、标注、评价和发布记录一并过滤。校核同时校验任务与候选版本，陈旧请求返回409。
- 本机状态保存在私有 `.runtime/platform.json`，原件仍在 `.runtime/ingestion/files/`；均不纳入 Git 或静态HTTP。模块后台与离线模型代码也不通过静态HTTP公开。
- 发布在同一持久化事务中保存已接受知识、本机名称索引与统计缓存；外部 Neo4j / 搜索引擎 / Redis 尚未接入，页面明确标识。
- 增量触发只响应治理交接，不绕过质量门槛；配置前已有交接不补建。停用期间不建任务，重新启用后可处理基线之后尚未消费的合格版本。
- 当前抽取器是可复现的结构化字段、术语与关系规则引擎，不含训练好的自然语言 NER 模型、大模型或任意文本推断。置信度是规则分流分值，不能视为校准后的正确概率。
- 本次实体与事实按来源记录保留，跨资料实体融合、复杂图查询属于后续图谱管理能力。
- 离线模式使用独立浏览器数据，真实文件上传与访问隔离需启动本机服务；两种模式互不同步。

## 开发与验证

主要新增 `src/construction.js`（页面）、`src/construction-core.js`（抽取和评价）、`src/construction-model.js`（版本、校核、发布、触发）、`server/construction.mjs`（后台队列）、`src/las-core.js`（LAS解析）。入口接入现有主页面、HTTP服务和离线打包。

接口包括 `GET /api/construction?projectId=…`、`GET /api/construction/task?projectId=…&taskId=…`、`GET /api/construction/graph?projectId=…`，以及 `POST /api/construction/{create,retry,review,issue,sample,evaluate,trigger,event-retry,publish,export-evaluation}`。写接口沿用登录会话、同源检查和CSRF。

运行 `npm test` 验证已有模块与新功能；运行 `npm run preview:build` 生成根目录的离线HTML。本次测试覆盖LAS限制、固定版本、实体与关系、原件 / 修正对照、审核冲突与权限、问题登记、发布门槛、严格评价、增量幂等、版本替代、HTTP与离线重开。
