# 样本标签清理与旧记录升级

版本：0.5.3。

清理范围包括界面文案、新样本的原始内容、井/层位/岩性/区块别名、治理记录、构建任务、人工校核记录、已发布事实及证据、图版本/快照、算法任务、规则输入和离线浏览器缓存。此前只隐藏名称前缀的处理已扩展为实际数据升级。

系统生成样本的原始文件会移除旧标签，同时更新关联版本、固定任务和审计引用中的摘要及文件大小。保留资料/任务/事实ID、版本链、校核/发布时间、业务数值与用户权限；证据高亮位置按清理后的原文重算。用户上传的非样本原件保持字节不变。

新版本机服务启动时执行升级。已停止服务时，可运行：

```powershell
npm run samples:clean
```

脚本检测 5173～5183 端口上的平台实例，避免覆盖运行中服务尚在内存里的状态。备份包含迁移前的数据库和被改写的系统样本文件，位于系统临时目录的 `knowledge-graph-backups` 内，项目代码与页面不读取该备份。迁移前发现原件摘要不一致会停止；提交失败会恢复原件。重复启动不会重复追加资料、任务或发布记录。

虚构数据仍通过“示例”“虚构”说明来源；本轮清理不把样本改称真实生产资料。旧离线预览请关闭后重新打开新生成的文件，以升级该浏览器独立保存的缓存。

新增五项自动化验证，覆盖旧格式与HTML编码、证据偏移、摘要与文件大小、备份/回退、原件损坏拒绝、重复启动、发布历史和凭据保护、离线缓存以及项目文本扫描。完整测试共88项。
